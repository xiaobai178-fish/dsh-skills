# 无电解电容（capacitor-less / 小母线电容）方案要点

> 典型场景：AC220V 输入、去掉了大容量电解电容（只留薄膜/小容值），母线电压是**整流后的馒头波**（100/120 Hz 脉动 + 逆变 6 倍频纹波）。深水泵、风机、压缩机常见。

## 1. 物理后果（决定了控制必须做什么）

| 现象 | 后果 |
|---|---|
| 母线电压 100/120 Hz 大幅波动（可能从 ~90 V 到 ~310 V） | 恒占空比会产生**拍频电流/转矩脉动**，转速与噪声抖动 |
| 母线电容小 → 母线电压对负载电流极敏感 | 突然加速会把母线拉到欠压，触发保护 |
| 逆变器 6 倍频纹波叠加 | 电流采样波形畸变，过零点附近信噪比差 |
| 无大电容缓冲 | 启动冲击电流大，需要软启动/限流 |

## 2. 代码里必须能找到的东西

| 功能 | 符号特征 | 为什么必须有 |
|---|---|---|
| 母线电压前馈 | `Vdc`/`Vbus` 参与占空比或 SVPWM 归一化 | 保持调制比恒定，压制拍频 |
| 母线电压纹波补偿 | `vbus_ripple`/`comp`/`feedforward` | 直接抵消 100 Hz 调制 |
| 拍频/转矩脉动抑制 | `beat`/`ripple`/`notch`/`resonant` | 抑制 2 倍频/6 倍频 |
| 启动限流/斜坡 | `soft_start`/`ramp`/`I_limit` | 防止母线塌陷 |
| 欠压/过压快速保护 | `UV`/`OV`/`brownout` | 电容小，跌落快 |
| 输入电压/电流过零检测 | `zero_cross`/`AC_sync` | 与电网相位同步（PFC 型方案） |

## 3. 两类主流控制思路

**A. 电压前馈型（最常见）**
- 观测/采样 `Vdc`，把 SVPWM 的调制比按 `Vdc` 归一化：`duty ∝ v_ref / Vdc`。
- 优点：改动小；缺点：`Vdc` 采样带宽要够（通常每 PWM 周期采一次，需滤波防抖）。

**B. 电流/功率主动整形型（PFC-like）**
- 让输入电流跟随整流后电压波形，母线能量按半周期平衡。
- 需要 `AC` 同步、`PFC`/`boost` 控制、`power factor` 相关符号；电机侧同时做转矩前馈。
- 优点：PF 高、母线可更小；缺点：控制复杂，启动与轻载难。

## 4. 采样窗口被压缩（最容易踩的坑）

- 单/双电阻采样依赖 PWM 占空比留出采样窗口；小母线电容方案里占空比波动大，**低占空比时采样窗口几乎消失** → 必须做**最小脉宽限制**或改为"上下管同时导通"的特殊采样时序。
- 看代码：`min_pulse`/`window`/`sample_delay`/`ADC trigger` 与占空比的联动。

## 5. 与普通 FOC 分析的差异（读码时的重点顺序）

1. 先找 `Vdc` 采样与使用点（有没有归一化/前馈）。
2. 再找保护阈值是否**动态**（随 `Vdc` 变化）而非固定常量。
3. 找启动流程（限流、斜坡、几次尝试）。
4. 找是否 AC 同步（有则大概率是 PFC-like 方案）。
5. 最后才是环路参数——因为纹波没处理时，环路参数再调也会抖。

## 6. 硬件相关（与读图技能联动）

- 薄膜电容容量与耐压、整流桥、母线检测分压比、`Vdc` 采样滤波时间常数（RC）、软启动继电器/NTC、EMC 的 X/Y 电容。
- 对账点：固件里的 `Vdc` 换算系数必须与分压比一致；欠压阈值必须高于实际纹波谷值留裕量。
