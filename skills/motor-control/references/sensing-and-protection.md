# 电流采样与保护（单/双/三电阻）

## 1. 采样拓扑判定

| 拓扑 | 代码/硬件特征 | 约束 |
|---|---|---|
| 三电阻（每相低边） | 3 路 ADC 通道，`ia/ib/ic` 同时采 | 最自由，可在任意时刻采 |
| 双电阻 | 2 路 + `ic = -(ia+ib)` | 需要窗口足够 |
| 单电阻（母线） | 1 路 `Ibus`，靠不同矢量组合**重构**相电流 | 占空比极端时窗口消失，需最小脉宽/移相 |
| 在线（inline） | 运放共模高，需专用电流检测放大器 | 关注共模电压与带宽 |

对账要点：**采样电阻位置**（低边/母线/在线）、阻值、运放增益、偏置电压 → 必须在固件里找到对应的换算常量。

## 2. 采样时机（决定数据对不对）

- 中心对齐 PWM：谷点（下管全开）或峰点采样；低边采样必须在**下管导通期间**。
- 三电阻常在计数器峰值/谷值触发；单电阻靠 `ADC SOC` 触发源与占空比配合。
- 检查：`ADC` 触发源是软件强制、EPWM SOC、还是定时器；`ACQPS`/采样保持时间是否足够。
- 常见错误：采样点落在开关沿上 → 电流尖峰/振铃 → 需要增加采样延时 `sample_delay`。

## 3. 零漂与标定

- 上电时**下管关断/零电流**条件下采零偏 `offset`，运行中做缓慢跟踪（`offset_track`/`zero_cal`）。
- 检查是否做温漂补偿；单电阻方案还要补偿运放失调。

## 4. 保护分层（量产必须三层）

| 层 | 实现 | 响应时间 | 代码特征 |
|---|---|---|---|
| 硬件 | 比较器 → PWM 封波（STM32 BRK/CBC、C2000 TZ/CMPSS） | µs 级 | `EPWM_setTripZoneAction`、`__HAL_TIM_MOE_DISABLE`、`CMPSS` |
| 中速 | ADC 采样超阈值 → 中断里立即关 PWM | 几十 µs | `OCP`/`overcurrent` 判断 + `shutdown` |
| 慢速 | 周期性软件保护（堵转、过温、欠压、缺相） | ms~s | 故障码表、`Error_code`、状态机 |

- 硬件阈值必须与采样电阻/比较器基准一致（读图对账）。
- 退饱和（desaturation）检测：大电流下驱动芯片报故障 → `DESAT`/`FAULT` 引脚。
- 母线过压：制动/回馈时容易触发，注意 `OVP` 时间常数要与电容值匹配。

## 5. 故障码设计（分析时先列出来）

- 看 `Error_code`/`fault`/`protect` 的枚举与分支顺序：谁先判、是否锁存、是否需断电复位。
- 常见清单：过流（硬件/软件）、过压、欠压、堵转、缺相、过温（MOS/NTC）、驱动故障、霍尔故障、通信超时。
- 复归逻辑：自动重试几次后锁死？重试间隔？——量产必须明确。

## 6. 与你工程的对照（南北星 STM32F0 例）

| 项 | 代码位置 | 说明 |
|---|---|---|
| 电流 ADC | `Adc.c` `ADC_Channel_2`（母线电流） | 采样时刻由 TIM1 触发 |
| 电压/温度 | `ADC_Channel_1`（电压）、`ADC_Channel_0`（温度） | NTC 公式在 `ParaCalcu.c` |
| 电压换算 | `Vol = Voltage*1283/10000` | 与分压比对应 |
| 硬件过流 | `TIM1` `TIM_Break_Enable` + `OC_Fault` 引脚 | BRK 输入，快关断 |
| 软件过流 | `Global.c` `Protect_Cur` / `PID_CUR` | 阈值与 4 mΩ 采样电阻相关 |
