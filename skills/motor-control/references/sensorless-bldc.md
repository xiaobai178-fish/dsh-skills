# 无感 BLDC（六步方波）读码要点

## 1. 反电动势过零检测

| 实现方式 | 代码特征 | 注意 |
|---|---|---|
| ADC 采三相端电压 | `ADC` + 中点比较 + `VBUS/2` | 需要中点电压（虚拟中性点或硬件中点） |
| 比较器/硬件 | `COMP`/`CMPSS`/`ACMP` + 中断 | 快，但要滤波防误触发 |
| 端电压分压后比较 | `BEMF`/`ZERO`/`CROSS` 命名 | 分压比必须与固件常量一致 |

- 过零后要等 **30° 电角度** 再换相：常用定时器延时 `30°_delay = T_60°/2` 或按 PWM 周期计数。
- 低速时 BEMF 幅值太小（∝转速），过零点淹没在噪声与死区非线性里 → 必须靠启动策略。

## 2. 启动三段法（几乎必备）

```
① 预定位（Alignment）：固定矢量通电 200~1000 ms，把转子拉到已知位置
② 开环加速（Ramp / I-f）：按斜坡升频，电流限幅；不依赖位置反馈
③ 切闭环（Handover）：检测到连续 N 个有效过零 → 切到 BEMF 换相
```
读代码找：`align`/`prepos`、`ramp`/`openloop`/`if_`、`handover`/`switch`/`closed`，以及切换判据（连续过零次数、转速阈值、时间窗）。

## 3. 换相与 PWM 调制

- 六步：每 60° 换相一次，任何时刻两相导通（一高二低）或三相调制（H-PWM-L-ON、H-ON-L-PWM 等）。
- 换相表：`HALL_NUM[6]`（有霍尔）或 `COMM_TABLE[6]`（无感，索引来自过零序列）。
- 调制方式影响电流纹波与采样：`PWM_ON`、`PWM_PWM`、`H_PWM_L_ON`。看 `switch/case` 里哪相被 PWM 驱动。
- 占空比与转速关系：六步是"电压→电流→转矩"，没有电流环时靠电压开环 + 限流保护。

## 4. 失步与堵转检测（量产必备）

- 过零超时：`zero_cross_timeout` / `Times_PWM_Lmt`（若干 PWM 周期内无换相 → 判堵转）。
- 转速突降 / 电流超限：`stall`、`jam`。
- 恢复策略：重启（重新预定位）还是锁死报故障，取决于产品要求。

## 5. 低速与重载难点

- 低速 BEMF 弱 → 用**脉冲注入/电感法**（`inject`/`pulse`/`inductance`，看电流上升斜率判断转子位置）或直接转 FOC+HFI。
- 负载突变导致失步 → 电流环 + 加速度限幅；纯电压开环方案必须留足裕量。

## 6. 与你现有工程对照

| 项 | 南北星 220V380（STM32F0） | 说明 |
